# Infos / Playbooks

Dieser Ordner ist die zentrale Ablage fuer wiederverwendbare Projektregeln.

Hier sollen spaeter alle dauerhaft gueltigen Spielregeln, Balancing-Entscheidungen,
Formeln, Datenquellenregeln und Admin-Ablaeufe gesammelt werden. Chatverlaeufe und
Arbeitsdokumente koennen Ideen enthalten, aber die Playbooks in diesem Ordner sind
die sauber aufbereitete Referenz fuer kommende Sprints.

## Aktuelle Playbooks

- `SPIELSTAERKE_PLAYBOOK.md` - Zusammensetzung der Spielerstaerke, Potential-Peak,
  RL-Form, Frische und aktuelle Beispielrechnungen.
