Greedy-Zuweisung kann falsche Ergebnisse erzeugen

Eine einfache Greedy-Auswahl nach Position kann scheitern.

Beispiel:

Spieler A kann LM und ZM spielen, Note 1,5
Spieler B kann nur LM spielen, Note 1,7
für ZM gibt es sonst keinen Kandidaten

Greedy würde Spieler A als LM wählen. Danach bleibt der ZM-Slot leer, obwohl mit B auf LM und A auf ZM eine vollständige Elf möglich wäre.

Deshalb sollte die Slot-Besetzung über eine kleine Backtracking- oder Matching-Funktion erfolgen.

Bei:

maximal elf Slots,
sieben Formationen,
ungefähr 200 qualifizierten Spielern,

ist das problemlos schnell genug, wenn vorher pro Slot nur die besten Kandidaten berücksichtigt werden.

Empfehlung:

pro Slot höchstens 10–15 passende Kandidaten
→ Backtracking mit Branch-and-Bound
→ beste vollständige Kombination ermitteln

5. Tatsächlich gespielte Position priorisieren

Für die Elf des Spieltags sollte zuerst die Position verwendet werden, auf der der Spieler in diesem konkreten Spiel eingesetzt wurde:

report_data.position

Nicht primär:

player.main_position_1

Ein Spieler, der im Spiel als Rechtsverteidiger eine 1,5 erhält, sollte anhand dieser Leistung als Rechtsverteidiger berücksichtigt werden – auch wenn seine Stammdaten ihn primär als Innenverteidiger führen.

Reihenfolge:

1. tatsächlich gespielte Position
2. normalisierte Position aus report_data
3. main_position_1 nur als Fallback
6. Positionskompatibilität definieren

Pro Slot sollte es exakte und kompatible Positionen geben.

Beispiel:

SLOT_COMPATIBILITY = {
    "GK": {
        "exact": {"TW"},
        "compatible": set(),
    },
    "LB": {
        "exact": {"LV"},
        "compatible": {"LOV", "LM"},
    },
    "LCB": {
        "exact": {"IV"},
        "compatible": {"LV", "RV"},
    },
    "LDM": {
        "exact": {"DM"},
        "compatible": {"ZM"},
    },
    "LAM": {
        "exact": {"LOM", "LF"},
        "compatible": {"LM", "OM"},
    },
    "ST": {
        "exact": {"ST"},
        "compatible": {"LF", "RF"},
    },
}

Dabei sollte ein kompatibler Einsatz einen kleinen Auswahlmalus erhalten:

fit_penalty = {
    "exact": 0.00,
    "compatible": 0.15,
}

Die Spielernote selbst wird nicht verändert. Der Malus dient nur der Elf-Auswahl.
