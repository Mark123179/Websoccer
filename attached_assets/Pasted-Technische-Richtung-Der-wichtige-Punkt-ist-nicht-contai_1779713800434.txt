Technische Richtung

Der wichtige Punkt ist: nicht contain, weil das wieder Leerfläche produziert.
Und wahrscheinlich auch nicht cover, weil Marker/Positionen dann durch Cropping schlechter passen können.

Für dein Ziel ist vermutlich am besten:

Bild/Background auf 100% Breite und 100% Höhe der Body-Fläche strecken.
Positionsmarker liegen auf derselben Fläche.

  max-height: none;
  object-fit: fill;
}
Warum fill hier richtig ist

Bei der POSITIONEN-Kachel ist das Spielfeld ein UI-Hintergrund mit Positionschips darüber. Wenn der Hintergrund und die Marker beide dieselbe Fläche benutzen, bleibt die optische Zuordnung stabil.

contain → Bild bleibt kleiner, erzeugt Leerraum
cover   → kann Pitch-Linien/Fläche croppen
fill    → nutzt die komplette Kachelfläche, Marker bleiben prozentual passend

Bei einem normalen Foto wäre fill oft falsch. Hier ist es als taktischer Hintergrund vertretbar.

(() => {
  const card = [...document.querySelectorAll("*")]
    .find((el) => /POSITIONEN/i.test(el.textContent || ""));

  if (!card) {
    console.table([{ error: "POSITIONEN-Karte nicht gefunden" }]);
    return;
  }

  const suspects = [...card.querySelectorAll("*")]
    .filter((el) => {
      const r = el.getBoundingClientRect();
      const cs = getComputedStyle(el);

      return (
        r.width > 100 &&
        r.height > 80 &&
        (
          cs.backgroundImage !== "none" ||
          el.tagName === "IMG" ||
          /pitch|field|position|formation|spielfeld/i.test(String(el.className || ""))
        )
      );
    })
    .map((el) => {
      const r = el.getBoundingClientRect();
      const cs = getComputedStyle(el);

      return {
        tag: el.tagName,
        className: String(el.className || "").slice(0, 160),
        width: Math.round(r.width),
        height: Math.round(r.height),
        ratio: Math.round((r.width / r.height) * 100) / 100,
        maxWidth: cs.maxWidth,
        maxHeight: cs.maxHeight,
        objectFit: cs.objectFit,
        backgroundSize: cs.backgroundSize,
        position: cs.position,
        overflow: cs.overflow
      };
    });

  const cardRect = card.getBoundingClientRect();

  console.table({
    viewport: `${window.innerWidth}×${window.innerHeight}`,
    cardWidth: Math.round(cardRect.width),
    cardHeight: Math.round(cardRect.height)
  });

  console.table(suspects);
})();
