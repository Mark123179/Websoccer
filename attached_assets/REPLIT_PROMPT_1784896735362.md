## 5. Spielmechanik (exakt, keine eigenen Regeln erfinden)

### 5.1 Annehmen
- "Annehmen" fixiert das Angebot für den Slot. Alle anderen Kandidaten des Slots → Badge "Abgesagt", 42 % Opacity, Buttons weg.
- Slot-Header zeigt dann: grüner Status "Vertrag fixiert", grüner Chip mit Logo + Name, Wert = Fix + erwarteter Bonus.

### 5.2 Nachverhandeln (max. 3 Runden pro Angebot)
- Erhöhungssätze pro Runde: **Runde 1: +7 %, Runde 2: +10 %, Runde 3: +12 %** — auf **Fixbetrag UND alle Bonus-Raten** (Multiplikator mitführen).
- Abbruchrisiko pro Runde: **18 % / 38 % / 62 %**. Würfeln BEIM Klick.
- Ablauf beim Klick: Karte pulsiert 1 s (cyan Glow-Puls, Button zeigt "Verhandelt …", alle Buttons gesperrt) → dann Ergebnis:
  - **Erfolg:** grünes Aufblitzen der Karte, Fixbetrag zählt animiert hoch (600 ms, ease-out), unter dem Betrag erscheint: alter Betrag durchgestrichen + grüner Chip `+X € fix · Boni +Y %`. Toast: "«Name» erhöht von X auf Y — die Boni steigen ebenfalls um +Z % (N Runde(n) übrig)."
  - **Abbruch:** rotes Aufblitzen, Karte → Badge "Verprellt" (rot), 42 % Opacity, dauerhaft raus. Toast rot.
- Fixbetrag nach Erhöhung auf 10.000 € runden. Nach Runde 3: Button-Text "Limit erreicht", disabled.
- Rundenanzeige: 3 Punkte unter dem Risikobalken (gefüllt = verhandelte Runde).
- Risikobalken: Breite = Risiko-%, Farbe grün <25 %, gelb <50 %, sonst rot.

### 5.3 Auto-Annahme (Pflicht-Feature, sichtbar kommunizieren)
- Bleibt in einem Slot nur noch **1** nicht-verprelltes Angebot: Badge "Auto-Annahme" (gelb), Verhandeln gesperrt ("Verhandlung gesperrt"), Annehmen-Button heißt "Jetzt fixieren". Hinweistext auf der Karte: "Letztes verbliebenes Angebot — wird zum Saisonstart automatisch angenommen."
- Zum Anpfiff des 1. Spieltags: Jeder noch offene Slot wird automatisch mit dem **SICHERHEIT**-Angebot besetzt (Startwert, ohne Verhandlungsrunden). Das SICHERHEIT-Angebot trägt in offenen Slots das cyan Badge "Auto-Wahl bei Anpfiff".
- Die gelbe REGEL-Box erklärt genau das (Text aus der Vorlage übernehmen).

### 5.4 KPIs & Szenario-Projektion (immer live berechnet)
- **Erwartetes Volumen** = Σ über alle Slots: fixiert/auto → Fix + varExp (mit Multiplikator), offen → Slotwert.
- **Worst Case** = Σ Fixbeträge (offene Slots: Slotwert). **Erwartet** = wie Volumen. **Best Case** = Σ Fix + varMax.
- Balken: Anteile Fix (cyan) / Variabel erwartet (grün) / Offen (grau) am Gesamtwert.
- "Slots fixiert" = n/5. "Verprellte Sponsoren" = Zähler, rot sobald >0.
