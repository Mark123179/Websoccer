Führe einen Golden-Master-Lock für stage-interne Layoutgeometrie ein.

Die aktuelle 1440×900-Ansicht ist die Referenz.

Alle strukturellen viewportabhängigen Werte innerhalb der Stage, die Layout, Breite, Höhe, Grid, Card-Größe oder Abstände beeinflussen, müssen auf die 1440×900-Golden-Master-Werte eingefroren werden.

Basis:
1vw = 14.4px
1vh = 9px

Aber:
Nicht blind alle vw-Werte global ersetzen.
Nur stage-interne strukturelle Layoutwerte:
- Artboard-Breiten
- Grid-Spalten
- Card-Min-Heights
- Gaps
- paddings/margins, wenn sie Layout verschieben
- Pitch-/Trophy-/Panel-Geometrie
Erwartetes Scaling

Mit der aktuellen logischen Stage:

BASE_WIDTH = 1884
BASE_HEIGHT = 1177.5

sollen die Viewports so laufen:

Viewport	Scale	sichtbare Stage-Breite	Rand links/rechts
1440×900	0.7643	1440px	0px
1920×1080	0.9172	1728px	96px
2560×1440	1.223	2304px	128px
3840×2160	1.834	3456px	192px

Diese Ränder sind dann echte Stage-Gutter, nicht verschenkter Innenraum.
Die dürfen mit Hintergrund/Chrome gefüllt werden, aber nicht durch Content-Stretching.

Abnahme-Messung

Replit soll bei /players/1519/ die logischen Maße der Kernkomponenten bei allen Auflösungen vergleichen:

(() => {
  const selectors = {
    stage: ".dashboard-scaler",
    profileGrid: ".aaa-profile-grid",
    poster: ".aaa-poster-card",
    positionsCard: ".aaa-position-card, .aaa-positions-card",
    pitch: ".aaa-pitch",
    marketCard: ".aaa-market-card",
    seasonCard: ".aaa-season-card",
    injuriesCard: ".aaa-injuries-card, [class*='injur']",
    transferCard: ".aaa-transfer-card, [class*='transfer']",
    careerSection: ".aaa-career-section, .aaa-career-grid",
    trophyCabinet: ".trophy-cabinet, [class*='trophy']"
  };

  const read = (selector) => {
    const el = document.querySelector(selector);
    if (!el) return null;

    const rect = el.getBoundingClientRect();
    const cs = getComputedStyle(el);

    return {
      selector,
      offsetWidth: el.offsetWidth,
      offsetHeight: el.offsetHeight,
      clientWidth: el.clientWidth,
      clientHeight: el.clientHeight,
      scrollWidth: el.scrollWidth,
      scrollHeight: el.scrollHeight,
      visualWidth: Math.round(rect.width),
      visualHeight: Math.round(rect.height),
      deltaX: el.scrollWidth - el.clientWidth,
      deltaY: el.scrollHeight - el.clientHeight,
      widthCss: cs.width,
      heightCss: cs.height,
      maxWidth: cs.maxWidth,
      minHeight: cs.minHeight,
      aspectRatio: cs.aspectRatio,
      transform: cs.transform
    };
  };

  console.table({
    viewport: `${window.innerWidth} × ${window.innerHeight}`,
    expectedScale: Math.min(window.innerWidth / 1884, window.innerHeight / 1177.5)
  });

  console.table(
    Object.entries(selectors).map(([name, selector]) => ({
      name,
      ...read(selector)
    }))
  );
})();
Harte Abnahme
Bei 1440×900:
Basis bleibt exakt wie jetzt.

Bei 1920×1080, 2560×1440, 3840×2160:
- offsetWidth/offsetHeight der Kernkomponenten bleiben gleich wie bei 1440×900
- nur visualWidth/visualHeight ändern sich durch transform scale
- .aaa-pitch behält aspect-ratio: 3 / 2
- Positionen-Panel sieht proportional identisch aus
- Trophy-Bereich sieht proportional identisch aus
- keine neuen internen Leerflächen
- keine neuen horizontalen Scrollbars
- keine neuen vertikalen Verschiebungen
