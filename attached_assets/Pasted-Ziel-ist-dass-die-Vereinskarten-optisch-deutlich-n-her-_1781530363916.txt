Ziel ist, dass die Vereinskarten optisch deutlich näher an der AAA-Vorlage liegen. Die aktuelle Darstellung ist zu flach und wirkt wie eine Tabelle.

1. Inhaltsbereich verbreitern

Der Bereich unterhalb des Kalenders soll die verfügbare Breite deutlich besser nutzen.

Kein schmaler, auf etwa 900px begrenzter Mittelblock.
Zielbreite auf Desktop ungefähr 1250–1450px.
Nur den Bereich .jo-artboard beziehungsweise dessen direkten Content-Wrapper verändern.
Kalender und Sidebar dürfen dadurch nicht beeinflusst werden.
.job-offers-page .jo-artboard {
  width: calc(100% - 48px);
  max-width: 1480px;
  margin: 0 auto;
  padding: 0 24px 60px;
}

Prüfe zusätzlich in den Developer Tools, ob ein übergeordneter Wrapper den Inhalt auf etwa 900px begrenzt. Diese Begrenzung ausschließlich innerhalb von .job-offers-page überschreiben.

Die Karten sollen keine 75px hohen Tabellenzeilen mehr sein.

Desktop-Ziel:

stärkerer Kartenhintergrund
dezenter Gold- oder Cyan-Hover

klare vertikale Trennlinien

Jede Karte zeigt immer:

Bewerbungsart
Button „Bewerben“
Link oder Button „Details“

Hat der Manager bereits einen Verein:

„Bewerben“-Button sichtbar lassen
Button deaktivieren
Text beispielsweise „NICHT VERFÜGBAR“
Tooltip: „Du stehst aktuell bei einem Verein unter Vertrag.“
Details bleiben anklickbar

8. HTML-Struktur des Aktionsbereichs

Der Aktionsbereich soll unabhängig vom Bewerbungsrecht immer vollständig gerendert werden:

<div class="jo-card-action">
  <div class="jo-badge jo-badge--free">
    <span class="jo-badge-icon">★</span>
    <span>Free Pick</span>
  </div>

  <button
    class="jo-apply-btn"
    disabled
    title="Du stehst aktuell bei einem Verein unter Vertrag."
  >
    Nicht verfügbar
  </button>

  <a class="jo-details-btn" href="...">
    Details
  </a>
</div>

Wenn sich der Manager bewerben darf:

<button class="jo-apply-btn">
  Bewerben
</button>

Der Button darf nicht vollständig aus dem DOM entfernt werden, nur weil der Manager aktuell einen Verein besitzt.

9. Responsive Verhalten

Auf großen Desktopbildschirmen muss die Karte immer in einer Zeile bleiben.

Erst unter ungefähr 1180px darf sie auf zwei Zeilen wechseln:

@media (max-width: 1180px) {
  .jo-card {
    grid-template-columns: 250px minmax(300px, 1fr) 100px;
  }

  .jo-card-comps {
    grid-column: 1 / 3;
    border-top: 1px solid rgba(255, 255, 255, .07);
  }

  .jo-card-action {
    grid-column: 3;
    grid-row: 1 / 3;
  }
}

Auf dem aktuellen Desktop-Screenshot darf dieser Breakpoint nicht greifen.

Abnahmekriterien

Die Änderung ist fertig, wenn:

Wappen ungefähr 80px groß sind.
Das Stadionbild den größten visuellen Bereich der Karte bildet.
Stadionbilder deutlich heller und lesbarer sind.
Karten mindestens ungefähr 125px hoch sind.
Wettbewerbe als richtige Checkliste dargestellt werden.
Free Pick, normale Bewerbung und Top-Bewerbung optisch klar getrennt sind.
„Bewerben“ beziehungsweise der deaktivierte Bewerbungsbutton immer sichtbar ist.
„Details“ weiterhin verfügbar ist.
Die Aktionsspalte nicht mehr unkontrolliert die gesamte Restbreite einnimmt.
Navigation und Kalender pixelgenau unverändert bleiben.
Jugendligazugehörigkeit und Jugendtabellenplatz vorbereitet oder angezeigt werden.
