Aktuell stochert Replit wieder. Der erste Wide-Fix hat nur gesagt:

Datumsspalte atmet
Textspalte bekommt übrige Pixel

Aber wenn der Text selbst noch so etwas hat:

max-width: 74px;
width: 74px;
overflow: hidden;
text-overflow: ellipsis;

oder wenn ein Parent-Wrapper die Breite begrenzt, bringt die neue Grid-Spalte nichts.

Dasselbe kann beim Spielerbild passieren: Wenn die Card breiter wird, das Bild aber eine feste Media-Höhe oder feste object-position/object-fit-Logik hat, siehst du keinen echten Nutzen.

  const cards = [

    const children = [...el.querySelectorAll("*")]
      .filter((child) => {
        const cr = child.getBoundingClientRect();
        return cr.width > 20 && cr.height > 10;
      })
      .slice(0, 12)
      .map((child) => {
        const cr = child.getBoundingClientRect();
        const ccs = getComputedStyle(child);

        return {
          tag: child.tagName,
          className: String(child.className || "").slice(0, 80),
          text: (child.textContent || "").trim().replace(/\s+/g, " ").slice(0, 60),
          w: Math.round(cr.width),
          h: Math.round(cr.height),
          clientW: child.clientWidth,
          scrollW: child.scrollWidth,
          dx: child.scrollWidth - child.clientWidth,
          width: ccs.width,
          maxWidth: ccs.maxWidth,

        };
      });

    return {

Wenn der Report zeigt, dass zum Beispiel die Verletzungstexte durch einen inneren Text-Span begrenzt sind, dann wäre ein echter Wide-only-Fix:

.dashboard-scaler[data-shell-mode="wide"] .ECHTER-INJURY-TEXT-SELECTOR {
  max-width: none;
  width: auto;
  min-width: 0;
}

Wenn der Report zeigt, dass die Poster-Media-Fläche das Problem ist:

.dashboard-scaler[data-shell-mode="wide"] .ECHTER-POSTER-MEDIA-SELECTOR {
  /* nur wenn sichtbar nötig */
}
