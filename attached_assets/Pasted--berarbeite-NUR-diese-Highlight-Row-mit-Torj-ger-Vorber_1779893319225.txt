────────────────────────
1. RANKING CARDS VERBESSERN
────────────────────────

Die drei RankingCards sollen stärker wie komponierte Premium-Sportkarten wirken.

Aktuelle Probleme:
- Spielerportraits wirken noch etwas klein.
- Rank-Badge, Spielerbild, Name und Wert sind noch nicht eng genug komponiert.
- Die Werte wirken noch nicht heroisch genug.
- Die unteren Flächen wirken teilweise leer statt bewusst hochwertig.

Bitte ändern:

- Spielerportraits ca. 10–15 % größer machen.
- Portraits in einem markanteren, leicht polygonalen/angewinkelten Frame zeigen.
- Rank-Badge stärker mit dem Portrait-Frame überlappen lassen.
- Rank-Badge nicht wie ein simples Quadrat wirken lassen, sondern als futuristisches Ranking-Plate.
- Name, Label und Wert näher an den Portraitblock setzen.
- Der Wert, z. B. 41 / 15 / 1.84, soll das klare zweite visuelle Zentrum der Karte sein.
- Wert größer machen, mehr Cyan-Glow geben, aber nicht übertreiben.
- Die drei Einträge sollen weiterhin vertikal angeordnet sein, aber nicht wie eine Tabelle wirken.
- Jede Entry-Zeile soll wie ein kleiner komponierter Spielerblock wirken.
- Die untere freie Fläche der Karten soll erhalten bleiben, aber durch sehr subtile HUD-/Sportgrafiken edler wirken:
  - schwache Linien
  - leichte Ballflugkurve
  - sehr dezentes Shield-/Pitch-Muster
  - minimale Partikel/Glow
  - keine dominanten neuen Bilder

RankingCard Layout-Regeln:

Jede RankingCard Entry soll ungefähr so aufgebaut sein:

[Rank Badge leicht überlappend] [Portrait in polygonalem Frame] [Name + Label + großer Wert]

Der Spielerblock soll dichter und hochwertiger wirken, nicht auseinandergezogen.

Nutze relative Größen mit clamp(), nicht starre Pixelwerte.

Beispielhafte Richtung:

.ranking-entry {
  position: relative;
  display: grid;
  grid-template-columns: clamp(46px, 3vw, 68px) clamp(78px, 5vw, 112px) 1fr;
  align-items: center;
  column-gap: clamp(8px, 0.8vw, 16px);
  min-height: clamp(92px, 6.5vw, 130px);
}

.rank-badge {
  z-index: 3;
  transform: translateX(clamp(4px, 0.4vw, 8px));
}

.player-cutout {
  z-index: 2;
  transform: translateX(clamp(-8px, -0.4vw, -4px));
}

.metric-value {
  font-size: clamp(24px, 1.7vw, 42px);
  font-weight: 900;
  color: #25f4ff;
  text-shadow: 0 0 12px rgba(37, 244, 255, 0.45);
}

Wichtig:
Die RankingCards dürfen NICHT zu normalen Listen oder Tabellen werden.
