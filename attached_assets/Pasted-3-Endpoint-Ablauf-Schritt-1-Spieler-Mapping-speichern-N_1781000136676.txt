3. Endpoint-Ablauf
Schritt 1: Spieler-Mapping speichern

Nicht jedes Mal neu suchen.

In deiner Datenbank pro Spieler speichern:

api_football_player_id
api_football_team_id
api_football_team_name
api_football_league_id optional
api_football_season
rl_form_updated_at

Wenn kein Mapping vorhanden:

RL-Form = 0
RL-Form-Fit = 1.00
Status = not_mapped
Schritt 2: letzte 10 Spiele des realen Teams holen

Sinngemäß:

GET /fixtures?team={team_id}&last=10

Oder, falls du sauber nur abgeschlossene Spiele willst:

status=FT-AET-PEN

API-Football beschreibt in einem eigenen Tutorial, dass man abgeschlossene Spiele über den Fixtures-Endpunkt mit Statuswerten wie FT-AET-PEN einschränken kann; Spielerstatistiken sind für abgeschlossene oder laufende Spiele sinnvoll verfügbar.

Für deinen MVP:

letzte 10 abgeschlossene Pflichtspiele des API-Teams

Keine Freundschaftsspiele, keine Nationalmannschaft, kein Fallback.

Schritt 3: Spielerstatistik je Fixture holen

Für jedes Fixture:

GET /fixtures/players?fixture={fixture_id}&team={team_id}

Daraus für den Zielspieler holen:

minutes
rating

Wenn Spieler nicht vorkommt:

minutes = 0
rating = null

Das zählt als „nicht gespielt“.

4. Berechnung

Für die letzten 10 Spiele:

possible_minutes = 10 × 90 = 900
played_minutes = Summe der gespielten Minuten
minutes_share = played_minutes / 900

Rating nur gewichtet nach Minuten:

weighted_rating =
    sum(rating × minutes) / sum(minutes)

Wenn keine Minuten:

weighted_rating = null
5. Rating in Formwert umwandeln

Nimm diese Tabelle:

Gewichtete Note	RL-Form
≥ 8.0	+5
7.7–7.99	+4
7.4–7.69	+3
7.1–7.39	+2
6.9–7.09	+1
6.5–6.89	0
6.3–6.49	-1
6.1–6.29	-2
5.9–6.09	-3
5.6–5.89	-4
< 5.6	-5

Beispiel:

weighted_rating = 7.32
→ rating_form = +2
6. Minutenanteil begrenzt die Aussagekraft

Ein Spieler mit 20 Minuten und Note 8.0 darf nicht direkt +5 bekommen.

Deshalb:

if not_fetched:
    rl_form = 0

elif played_minutes == 0:
    rl_form = -2

elif played_minutes < 90:
    rl_form = min(0, round(rating_form × 0.25))

elif played_minutes < 270:
    rl_form = clamp(round(rating_form × 0.50), -3, +2)

elif played_minutes < 540:
    rl_form = clamp(round(rating_form × 0.75), -4, +3)

else:
    rl_form = rating_form

Das ist simpel und fair.

Beispiele:

720 Minuten, Note 7.4 → +3
390 Minuten, Note 7.4 → +2
140 Minuten, Note 7.8 → +2
45 Minuten, Note 8.1 → 0
0 Minuten → -2
nicht abgefragt → 0

Das passt zu deiner Logik:

gute Leistung + viel Spielzeit = echter Formbonus
gute Kurz-Einsätze = kleiner oder kein Bonus
keine Einsätze = Malus
keine API-Abfrage = neutral
