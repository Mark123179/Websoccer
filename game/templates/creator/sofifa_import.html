Da SoFIFA das Scraping blockiert, werden Ratings über eine lokale CSV-Datei importiert. Das Matching läuft primär über die sofifa_id; fehlt eine verknüpfte ID, greift ein Fallback über Name + Verein und speichert die ID dauerhaft.

Pflichtfelder im CSV-Header:

sofifa_id, overall (oder rating)

Optionale Spalten:

name, club, potential, profile_url,
tempo, ausdauer, kraft, technik, dribbling, passspiel, flanken,
abschluss, kopfball, zweikampf, defensivstellung, uebersicht, teamwork,
ecken, freistoss, elfmeter,
tw_reflexe, tw_fangsicherheit, tw_eins_gegen_eins, tw_stellungsspiel, tw_passen

Englische SoFIFA-Labels (acceleration, stamina, finishing …) werden automatisch erkannt.
